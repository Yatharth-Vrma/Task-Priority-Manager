# Walkthrough Video

Place your walkthrough video file in this folder (e.g., `walkthrough.mp4`).

## How it appears in the README

The main `README.md` is configured to display the video. Once you add the video:

1. Place the file here: `video/walkthrough.mp4`
2. Push to GitHub
3. The README will show the video player automatically

## Supported Formats

GitHub supports embedding these formats via `<video>` tag:
- `.mp4` (recommended — best browser support)
- `.mov`
- `.webm`

**Max file size**: GitHub allows up to 100 MB per file. If your video is larger, use [Git LFS](https://git-lfs.github.com/) or upload to YouTube/Loom and update the README link.

## Alternative: External Video Link

If using YouTube or Loom, update the video section in the root `README.md` to use your external link instead.
